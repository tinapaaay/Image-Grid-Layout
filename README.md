# Image Grid Layout

A responsive image gallery built with HTML and CSS Grid.

This project arranges six local images into an asymmetric grid layout that adapts across desktop, tablet, and mobile screen sizes.

## Features

- Six-image gallery
- Asymmetric CSS Grid layout
- Local image assets
- Responsive desktop, tablet, and mobile layouts
- Image hover zoom effect
- Accessible alternative text for every image

## Built With

- HTML5
- CSS3

## What I Practiced

- Creating grid containers with CSS Grid
- Defining columns and rows
- Spanning grid items across columns and rows
- Responsive layouts with media queries
- Image cropping with `object-fit: cover`
- Image spacing and alignment

## Run locally

From the repository root, run `python3 -m http.server 5500`, then open [localhost:5500](http://localhost:5500). Python 3 is only a development-server option; VS Code Live Server also works. Stop the server with Ctrl+C. No package installation or build is required to serve this checkout.
